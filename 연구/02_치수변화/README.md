# 후속 치수 연구

이 폴더는 후속 연구 입구다. 이 문서 자체는 계산 수행이나 기준 소자 물리 검증 통과의 근거가 아니다.

첫 GAA Id–Vg의 실제 구조·수렴·메시·모델 검증 후 진행한다. 길이, Si 단면, 산화막 두께를 한 변수씩 바꾸고 바이어스·정규화·모델을 통제한다. 폴더 생성은 sweep 실행이 아니다.

[기준 소자 목표](../01_GAA_IdVg/md/설계와목표.md)와 [후속 사전계획](../../md/연구계획/후속실험_사전계획_20261124.md)을 먼저 확인한다. 팀원별 실제 시도는 [최상위 팀원 공간](../../md/협업/팀원공간.md)에 새 실행 ID로 보존하고, 공동 채택된 덱/분석은 검토 후 이 연구 공간에 통합한다.
