# 팀원별 TCAD 실험

각자 이름 아래 `주제/실행ID/`를 추가한다. 같은 파일을 함께 편집하지 않아도 각자의 폴더에서 실험을 찾을 수 있다. 이 표에 매 실행마다 행을 추가할 필요는 없다.

| 권도현 | [권도현](권도현/README.md) |
| 윤석영 | [윤석영](윤석영/README.md) |
| 박선우 | [박선우](박선우/README.md) |
| 진 | [진](진/README.md) |

[시작 안내](../../md/협업/README.md) · [공유 규칙](../../md/협업/실험공유규칙.md) · [빈 양식](../../md/양식/실험/README.md)

생성 예(저장소 루트에서):

```powershell
py -3.11 python/collaboration/new_run.py --member 권도현 --topic gate_length --run-id 20261125_lg40_r01
```

폴더 생성은 실제 TCAD 실행이 아니다. 다른 사람의 폴더·공용 자동화·과거 실행 원본을 수정하지 않는다.
