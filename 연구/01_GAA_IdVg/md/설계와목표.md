# 첫 GAA nMOS 기준 소자와 사전 목표 v1

2026-11-16, 실제 전류 결과를 보기 전에 설정. [출처](../../../문헌/README.md).

첫 단계는 단일 직사각 Si 나노와이어의 **실제 3차원** 모델이다. 전류 방향은 z, 단면은 x–y이다. 채널의 상하좌우를 SiO2와 하나의 전기적 게이트가 감싼다. 원통의 2D 축대칭 해석으로 대체하지 않는다. DRAM 저장 셀이나 회로 표준 셀까지 제작한 것으로 표현하지 않는다.

| 항목 | 기준값 | 근거/성격 |
| --- | --- | --- |
| 게이트 길이 | 40nm | 초기 DD/수렴 점검용 설계 선택. R1의 16nm 재현과 구별 |
| Si 단면 | 10×10nm | R1의 비교 단면 범위 내 정사각 기준; 유효 둘레 40nm=0.04um |
| 소스/드레인 Si 길이 | 각각 20nm | 접촉 분리용 설계 선택, 급격한 n+/p/n+ 접합 |
| SiO2 두께 | 1nm | R4 기반; R1의 high-k 적층을 재현하지 않음 |
| gate 두께 | 3nm | 이상적인 금속 접촉의 기하 선택 |
| 채널 p형/소스·드레인 n형 | 1e16 / 1e20 cm^-3 | R4 기반. 도핑은 구조 로딩 후 ATLAS에서 설정 |
| gate work function | 4.5eV | 초기 설계 가정. 임계값 맞춤 보정 전이며 실제 금속 공정 재현 아님 |
| 온도 | 300K | 평가 조건 |
| Vds | 0.05V, 0.6V | 저전압/동작전압 분리; 동작전압은 R1 참고 |
| Vgs | -0.2~0.8V, 0.02V 간격 | off=0V, on=0.6V. 추가 범위는 곡선/문턱 검사 |
| 초기 물리 모델 | DD, FERMI, CONMOB, FLDMOB, SRH, BGN | 문법·구조 smoke용. 계면 이동도·양자 보정·터널링 미보정 |

## 선행 검사

DevEdit의 3D region/전극/메시 생성, 출력 구조의 3차원 좌표와 전극/도핑 판독, 평형 수렴, 짧은 gate sweep, 실제 라이선스/return code/로그/필수 출력부터 확인한다. coarse XY Si 최대1nm, 산화막0.25nm, gate3nm, z 최대2nm이며 gate 경계/중앙은1nm로 제한한다. fine은 이들 간격을 절반으로 한다. 실제 메시에서 계면 분해능을 확인해야 한다.

## 정량 기준

다음은 문헌 성능의 복제가 아닌 **사전 공학 목표**다. R1의 보정된 16nm GAA는 SS 약61–67mV/dec와 낮은 DIBL을 보고한다(Table II). 이를 참고하되 긴 채널·단순 모델의 첫 동작 판별에 더 넓은 허용 범위를 사용한다.

- Vgs=Vds=0.6V에서 Ion ≥ 100uA/um(둘레 정규화), 즉 단일 wire 4uA.
- Vgs=0V, Vds=0.6V에서 Ioff ≤ 1nA/um, 즉 단일 wire 4e-11A; Ion/Ioff ≥ 1e6.
- 동일한 1e-10~1e-8 A/um 구간의 log10(Id)–Vgs 선형 회귀로 SS 60~90mV/dec. 전류창을 두 sweep이 충분히 덮지 않으면 NOT_EXTRACTABLE. 최소6점·2dec 범위를 요구하며 numerical-floor 의심값은 물리 결론에서 제외한다.
- Vth는 둘레당100nA/um의 일정전류 방식으로 두 Vds에서 추출한다. 저 Vds Vth는0.1~0.5V를 목표로 하고 DIBL=(Vth_low-Vth_high)/0.55, 0~50mV/V를 목표로 한다.
- DC KCL 잔차 ≤ max(1e-14A, 최대단자전류의0.1%). NaN·누락 점·전극 단락·미수렴 점은 제외하지 말고 실패로 처리한다.
- coarse→fine에서 Ion 변화≤5%, Vth≤10mV, SS≤5mV/dec; Ioff가1e-15A 이상이면 변화≤20%. 더 낮으면 절대 변화와 전류 floor/오차를 따로 보고한다.

게이트 누설이0으로 계산돼도 터널링 모델이 꺼져 있으면 실제 누설 검증이 아니다. 고전적 DD가 위 목표에 들어와도 물리 검증 통과로 판정하지 않는다. 계면 이동도와 양자 보정을 설치 버전에서 확인하고 R1 또는 적절한 보정 자료와 비교한 뒤 최종 신뢰 범위를 적는다. 16nm 축소와 high-k 변경은 첫 기준 소자의 검증 후 별도 실험으로 진행한다.
