# 검증 범위

[상태.json](상태.json)은 이 변경을 검증한 시점의 기록이다. live 상태는 Git 밖 세션 runtime과 `control.py status`가 제공한다. Git의 상태 파일을 heartbeat로 사용하지 않는다.

로컬 합성/localhost 시험은14개 통과했다. 실제 원격 실행 시도와 오류 수정은 [실행시도.md](실행시도.md)에 기록한다. 라이선스·수렴·물리 검증 통과는 아직 확인하지 못했다. 로컬 검증 로그는 [로컬검증.txt](로컬검증.txt)에 보존한다. 가짜 Id–Vg 데이터/성능 그림은 만들지 않았다.

중계 r01은 원격 agent 등록 없이 종료했다. 새 백그라운드 세션에서는 agent가 등록됐고 supervisor가 설치 환경 진단 패키지를 자동 제출·회수했다. preflight는 시뮬레이션이 아니다. 현재 Codex가 파일/상태 API로 smoke 시험을 진행하며 새 작업 ID별 실제 원시 자료를 해석한다.

이후 결과를 추가할 때는 job ID, 입력/출력 SHA-256, 툴 버전, 종료 코드/종료 표시, 오류/수렴, 실제 구조·도핑·전극, 메시 수렴, 단위·정규화, 목표 대비 수치를 함께 남긴다. 회수 성공과 물리적 성공은 별개다.
