# 검증 범위

[상태.json](상태.json)은 이 변경을 검증한 시점의 기록이다. live 상태는 Git 밖 세션 runtime과 `control.py status`가 제공한다. Git의 상태 파일을 heartbeat로 사용하지 않는다.

로컬 합성/localhost 시험은13개 통과했다. 실제 Silvaco 실행·라이선스·수렴·물리 검증은 아직 수행하지 못했다. 검증 로그는 [로컬검증.txt](로컬검증.txt)에 보존한다. 가짜 Id–Vg 데이터/성능 그림은 만들지 않았다.

중계 r01은 원격 agent 등록 없이 종료했다. 새 백그라운드 세션은 화면 제어 없이 최초 agent 등록을 기다리며, 등록되면 supervisor가 설치 환경 진단 패키지를 자동 제출·회수한다. preflight는 시뮬레이션이 아니다. 설치 환경을 검토한 뒤 Codex가 smoke→full→fine을 새 작업 ID로 제출하고 실제 원시 자료를 해석한다.

이후 결과를 추가할 때는 job ID, 입력/출력 SHA-256, 툴 버전, 종료 코드/종료 표시, 오류/수렴, 실제 구조·도핑·전극, 메시 수렴, 단위·정규화, 목표 대비 수치를 함께 남긴다. 회수 성공과 물리적 성공은 별개다.
