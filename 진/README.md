# 진의 연구 공간

저장소 최상위의 개인 공간이다. 이름과 GitHub 계정·접근 권한은 별개다.

| 폴더 | 내용 |
| --- | --- |
| [문헌](문헌/README.md) | 출처·읽기 기록 |
| [연구](연구/README.md) | 주제/실행ID별 실험과 결과 |
| [md](md/README.md) | 개인 연구 노트·계획 |
| [python](python/README.md) | 개인 공통 도구 |
| [검증](검증/README.md) | 개인 공통 검증 기록 |
| [그림](그림/README.md) | 개인 공통 그림 |

각 실행의 덱은 `연구/주제/실행ID/tcad/`, 로그는 `연구/주제/실행ID/검증/raw/`에 둔다. 수정·재실행은 새 ID로 보존한다. 이 폴더를 만든 것만으로 계산을 수행한 것은 아니다.
