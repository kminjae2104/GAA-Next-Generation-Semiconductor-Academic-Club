# 설치된 3D 양자 예제의 설정

2026-11-16 원격 Linux의 실제 설치 예제를 읽기 전용으로 조회했다. 경로는 `/users/tools/Silvaco/examples/deckbuild/4.2.15.R/quantum/quantumex08/quantumex08.in`, 파일 머리말은 `(c) Silvaco Inc., 2022`이다. 디렉터리 이름4.2.15.R은 실제 실행한 ATLAS5.34.0.R 버전과 구분한다.

이 예제는 DevEdit `-3d` 구조를 사용하며 Si 단면10×15nm를 정의한다. BQP 전자 보정의 설정값은 `gamma=1.4`, `alpha=0.3`이다. 예제는 에너지 수송도 함께 사용하므로 전체 모델을 그대로 복사하면 양자 보정만의 효과를 분리할 수 없다.

이번 비교는 기존의 DD·도핑·치수·일함수·온도에 `BQP.N`과 위 두 계수만 추가한다. 물리 모델 차이를 기록하고 같은 소자·메시에서 고전적 DD와 비교한다. 이 계수는 설치 예제에서 차용한 시작값이며, 우리10×10nm 소자에 대해 실측 또는 Schrödinger–Poisson으로 보정된 값이 아니다. 결과가 목표 안에 들어와도 실측 보정 완료라고 주장하지 않는다.

원문 출처인 제조사 예제 전체는 재배포하지 않는다. 읽은 설정과 경로는 Git 밖 진단 패키지 `gaa_modelhints_20261116_r02/installed_quantum_examples.json`에 보존했다. 이 비교의 목적은10nm 단면의 양자 보정 누락 영향을 분리해 보는 것이다. [제조사 BQP 기술 자료](https://silvaco.com/ko/simulation-standard-ko/comparison-of-3-dimensional-quantum-effects-in-nano-devices-using-the-atlas-3d-bqp-model/)와 [주요 문헌](README.md)도 함께 참조한다.
