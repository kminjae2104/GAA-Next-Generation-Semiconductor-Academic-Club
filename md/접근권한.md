# 저장소 공개 범위와 부원 조회

2026-11-16 GitHub 연결에서 저장소 소유자는 개인 계정 `kminjae2104`, 공개 범위는 `private`, 기본 브랜치는 `main`, 연결 계정은 관리/쓰기 권한을 가진 것으로 확인했다. 사용자는 현재 공개 범위 유지를 선택했다. 이메일만으로 로그인 사용자를 판단하지 않는다.

현재 개인 비공개 저장소에는 특정 동아리원을 읽기 전용 collaborator로 초대하는 공식 권한 모델이 없다. collaborator는 쓰기도 가능하다. branch protection만으로 저장소 전체를 읽기 전용으로 만드는 것은 별개 문제다.

부원만 조회하도록 하려면 조직 소유의 비공개 저장소에서 부원에게 `Read`, 본인에게 `Admin` 권한을 부여하는 구성이 적합하다. 조직 이름·부원 계정·이전 여부가 정해지면 별도 작업으로 진행한다. 현재는 공개 전환·초대·권한 변경·소유권 이전을 하지 않는다.
