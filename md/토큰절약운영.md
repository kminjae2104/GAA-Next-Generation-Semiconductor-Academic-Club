# 토큰 사용을 줄이는 운영

2026-11-16 사용자 요청을 반영했다.

- `watch_job.py`가10초 간격으로 로컬 receipt만 확인한다. 대기/파일 검사에 모델 호출을 사용하지 않는다.
- 결과 ZIP 회수·해시 검증·원시 로그에서 버전/메시/오류 추출·전류 수치 분석은 Python이 수행한다.
- 모델에는 Git 밖 runtime의 `latest_summary.json`만 우선 전달한다. 원시 로그는 원인 규명에 필요한 부분만 읽는다.
- 변경 없이 같은 상태를 반복 조회하거나, 수정과 무관한 테스트를 반복하지 않는다. 실패 시 새로운 증거를 확보한 뒤 새 job으로 수정한다.
- 자동으로 읽는 상태는 직전 요약/에러 최대5줄/주요 지표로 제한한다. 전체 원시 파일과 해시는 별도로 보존한다.
- 화면·마우스·키보드·클립보드는 사용하지 않는다. 자동 오류 처리가 과학적 원인 판정을 대신한다고 주장하지 않는다.

controller/agent 및 Python 감시기가 돌아간다는 사실은 Codex 모델이 대화가 끝난 뒤에도 스스로 생각하며 수정한다는 뜻은 아니다. 모델 판단이 필요한 미분류 오류는 요약에 남기며 다음 검토 때 해당 부분만 처리한다.
