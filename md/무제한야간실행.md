스케줄러는 실제로 별도 Linux 세션인 것을 PID/session ID로 확인했다. MobaXterm·Google 원격 데스크톱·중계 agent가 끝나도 이 계산에 종료 신호를 보내지 않는다. 스케줄러의 모델 호출과 계산 시간 제한은 없다.

`connection_guard.py`가 30초 간격 로컬/공개 HTTPS 상태와 agent heartbeat 나이를 기록하고 10분 간격 읽기 전용 스냅샷을 회수한다. agent는 통신 실패 후 기존 연결을 재시도하며 실행했던 작업 ID를 다시 실행하지 않는다. 스냅샷은 원시 로그 전체를 대신하지 않으며, 완료된 조건의 원본 전류 로그·추출값·검증 수치와 진행 요약을 회수한다. 큰 구조와 전체 solver 로그는 서버에 보존한다.

Windows `SetThreadExecutionState`로 중계 PC의 유휴 절전을 방지한다. 디스플레이 설정·화면 잠금·마우스·NumLock·클립보드는 조작하지 않는다. 중계는 24시간이고 계산은 별도 무제한이다. Google 원격 데스크톱의 인증/관리 정책으로 인한 화면 세션 만료와 정전·네트워크 단절까지 보장하지 않는다. 화면 연결 유지 여부와 TCAD 계산 지속 여부를 구분한다.

