# 운영과 과거 기록 색인

과거 문서의 공개 범위·권한·실행 시각·기한 설정은 당시 기록이다. 현재 권한 선택은 [접근권한](../접근권한.md), 팀원 제출은 [협업 안내](../협업/README.md)를 우선한다. 계산과 통신에 예정 만료 기한을 두지 않는 최신 규칙은 AGENTS.md를 따른다. 과거의 시간 제한 예시를 새 작업에 복사하지 않는다.
