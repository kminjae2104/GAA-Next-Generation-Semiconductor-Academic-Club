# GAA 전체 결과 감사와 연구주제 도출 실행 프롬프트

작성일: 2026-11-24 KST. 사용자 요청에 따라 이 문서를 먼저 저장하고 곧바로 수행한다.

## 목적과 범위

C:\dev\gaa에 보존된 모든 TCAD 실행 계열을 조사하여 실행 ID, 덱/모델/치수, 정상 종료, 바이어스, 수치 검증, 성능 목표, 메쉬/물리 검증을 구분한 총정리와 후속 실험 계획을 작성한다. 실제 결과에 나타난 경향을 출발점으로 TCAD 검증 가능한 연구주제를 제안하고 공신력 있는 원문 논문 및 공식 문서로 중복 가능성과 구현 가능성을 검토한다.

## 수행 지시

1. AGENTS.md, 브랜치와 미커밋 변경, README, 설계와목표 및 기존 연구계획을 읽는다. 기존 변경과 원시 덱/로그/구조는 보존한다.
2. `.local/collected`, 연구별 검증, 최상위 검증의 모든 실행 계열을 목록화한다. 반복 수집본을 독립 실험으로 세지 않는다. SHA-256과 원시 경로, snapshot 시각으로 출처를 남긴다.
3. 등록된 agent/파일 API의 현재 상태를 한 번 확인한다. 가능한 경우 읽기 전용 snapshot을 회수한다. 화면, 키보드, 마우스, 클립보드는 사용하지 않는다. 연결 불가 시 최신 보존본의 시각과 누락 가능성을 명시한다. 원격 계산을 대기하거나 반복 조회하지 않는다.
4. 기존 분석기를 검토하고 원시 로그/terminal export로 수치를 재검산한다. 실제 native 바이어스, return code, 정상 종료, KCL, forward/reverse, 메쉬를 따로 확인한다. A와 둘레 정규화 A/um를 구분한다. floor 전류/추출 불가능 지표는 제외하지 말고 한계로 기록한다.
5. 초기 실패·smoke·야간 DAG·후속 continuation·explicit-bias 복구 계열을 포함한다. 수치 실행 성공, 성능 목표 충족, 물리 타당성 확보를 혼동하지 않는다. 아직 계산되지 않은 치수 변화의 추세를 만들지 않는다.
6. 현재 관측에서 가능한 주장과 불가능한 주장을 나누고, 고정 임계값에 대한 일함수 이동 효과와 실제 구동력 변화/수치 오류를 분리한다.
7. 선행연구는 IEEE/학회 원문, DOI 출판사, 연구기관 및 Silvaco 공식 문서를 우선한다. 검색어·검색일·DOI/URL·확인 범위·이미 다뤄진 내용·남은 차별점·중복 위험을 기록한다. 검색에서 발견되지 않았다는 이유로 세계 최초나 비중복을 확정하지 않는다.
8. 먼저 기준 소자의 수치/모델 검증을 완료하도록 후속 실험의 선행 조건, 독립 변수, 대조군, 추출식, 판정 기준, 실패 시 처리, DAG 순서를 사전 등록한다. 최대 3개 병렬, 검증 통과 즉시 개별 후속 시작, 시간 제한 없음 원칙을 따른다.
9. 연구주제는 현재 도구에서 실행 가능한 주제와 추가 모델/교정이 필요한 주제를 구분한다. 우선 주제 1개와 대안, 반증 조건, 기대 산출물, 진행/보류 기준을 제시한다.
10. 문서는 md/, 계산·목록화 코드는 python/, 재계산 및 출처 자료는 검증/, 과학 그래프는 그림/에 새 파일로 저장한다. 이번 요청은 결과 분석과 실험 설계이며 신규 원격 TCAD 제출이나 기존 자동화 변경은 수행하지 않는다.

## 결과물과 완료 기준

- 전체 실행/조건 목록과 재계산 기록, 누락·중복·불완전 결과의 명시.
- 근거를 연결한 한국어 총괄 보고서, 사전 기준을 포함한 후속 실험 계획, 선행연구 비교와 연구주제 제안.
- 재현 가능한 Python 명령 및 실제 수행한 검증 기록. 확인되지 않은 수치·신규성·물리 보정을 통과로 표시하지 않는다.
- 필요한 핵심 정보가 저장소와 등록 API에서 확인되지 않을 때만 사용자에게 질문한다. 목표는 소자 연구 결과와 계획이며 형식은 저장소 관례의 Markdown으로 가정한다.
