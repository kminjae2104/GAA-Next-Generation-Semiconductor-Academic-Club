# 통신 복구와 결과 총분석 실행 계획

2026-11-20 사용자 지시: agent 연결 복구, 통신 만료 기한 제거, 원격 완료 범위 확인, 전체 결과 분석.

현재 main과 기존 미추적 발표 자료를 보존한다. 기존 실행과 원시 덱·로그·구조를 수정하거나 다시 제출하지 않는다. 화면 활성화·스크린샷·입력 장치·클립보드를 쓰지 않는다.

1. 중계·agent·절전 방지·감시에서 0/null을 무기한으로 지원한다. TLS, 토큰 인증, SHA-256 검증과 명시적 중지 기능은 유지한다. 무기한은 예정 종료가 없다는 의미이며 외부 네트워크 가용성을 보증하지 않는다.
2. 인증 HTTPS 중계를 실제 확인하고, 등록된 agent의 재연결 가능 여부를 확인한다. 기존 접점이 사라졌으면 새 bootstrap 등록이 필요한 사실을 밝히고 안전한 수동 등록 안내를 준비한다.
3. 원격 3개 실행 ID의 상태·완료 표식·프로세스·실제 종료 코드·로그·native/export·검증 결과를 불변 snapshot으로 회수한다. 연결 전에는 11/18 최종 회수본으로만 예비 분석한다.
4. 사전 설계 목표를 유지하고 기능 시험/수치 통과/공학 목표/메시/물리 보정을 구분한다. 단일 소자 A와 둘레 정규화 A/um를 분리한다. 누락·잘린 스윕을 완성된 성능으로 사용하지 않는다.
5. 모델 대기 조회 없이 Python이 30초 통신 점검, 10분 회수와 해시 검증을 수행하도록 준비한다. 최신 연결/분석 한계를 보고한다.
