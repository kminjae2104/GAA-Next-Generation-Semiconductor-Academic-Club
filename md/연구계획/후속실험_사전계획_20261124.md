# 다음 GAA 실험 사전계획

2026-11-24. 아래 기준은 **새 실험 결과를 보기 전에** 정했다. 이번 요청에서는 분석과 계획을 수행했으며 신규 TCAD는 제출하지 않았다. 기존 실행과 실패 판정은 보존한다.

## 1. 실험 목적과 순서

현재 검증이 가장 완결된 조건은 DD 4.60 eV full/fine이다. 4.55 eV fine은 코드 143으로 실패했고, BQP full은 11월 24일 11:17 KST에도 목표 Vds를 확보하지 못한 채 실행 중이었다. 일함수 변화는 거의 순수한 Id–Vg 전압축 이동으로 나타났다.

따라서 **기준 결과의 신뢰 범위 확정 → 공간 배치 비교 → 같은 누설로 맞춘 뒤 남는 차이 확인**의 순서로 진행한다. 기존 공학 목표와 새로운 연구의 효과 판정 기준을 분리한다.

## 2. 준비와 수치 복구

A2의 코드 143만으로 신호의 주체나 원인을 확정하지 않는다. 실패가 빠르게 발생했다는 사실을 소자의 물리적 불안정성으로 해석하지 않는다. A3에서도 수치 설정 변경과 물리 모델 변경을 별도 실험으로 기록한다.

계산 경과시간에 따른 자동 종료 기한은 두지 않는다. 실제 바이어스·출력·수렴 검사에서 실패한 단계의 후속을 보류하는 것은 시간 제한과 다른 과학적 검증 조건이다.

### 공통 모델 교정 규칙

1. 기하·재료·도핑·바이어스와 측정 정의가 명확한 기준 자료를 먼저 선택하고 출처를 등록한다. SISPAD 2020의 16 nm/high-k/다른 도핑 조건에 현재 40 nm/SiO2 소자의 Ion만 맞추지 않는다.
2. 필요하면 기준 논문의 소자를 별도 reproduction 실험으로 만든다. 논문의 정규화·추출 정의와 자체 사전 지표를 나란히 계산한다.
3. 전하/정전용량의 시작 허용값은 공통 전압 구간 Q(Vg) 또는 C–V의 정규화 RMS 오차 10% 이하, 문턱 차이 20 mV 이하다. 자료의 측정 불확실성이 더 크다면 결과 생성 전에 근거와 새 기준 버전을 기록한다.
4. 전류의 잠정 교정 기준은 두 Vds에서 문턱 아래 log10(Id) RMS 오차 0.15 decade 이하, on 전류 차이 15% 이하, SS 차이 5 mV/dec 이하다. 이는 이번 연구의 사전 허용값이며 제조사가 보장하는 정확도나 표준값이 아니다. 교정에 사용하지 않은 전압점 또는 다른 길이 한 개를 검증용으로 남긴다.
5. 구판 ATLAS S–P의 단일 구속 방향 제약을 확인한다. 평면 1D 교정을 사각 wire의 두 횡방향 구속에 대한 완전 검증으로 쓰지 않는다. 별도 횡단면 S–P 또는 검증된 양자 자료를 확보하지 못하면 그 한계를 남긴다.
6. 교정한 공통 모델과 계수는 모든 산화막 순열에 고정한다. 원하는 순위를 얻기 위해 조건별로 다시 조정하지 않는다.

## 3. 주제의 가설과 대조군

주제는 **같은 산화막 두께 분포에서 축방향 배치가 만드는 일함수 보상 한계**다.

- H0: 단일 gate work function으로 같은 Ioff를 맞추면 배치에 따른 차이가 수치 불확실성 안으로 사라진다.
- H1: 같은 Ioff를 맞춰도 소스 장벽과 드레인 결합이 달라져 SS·DIBL·Ion 중 일부 차이가 남는다.
- 반증 조건: 메시·표본 간격·모델 교정 후 차이가 사라지거나 아래 판정 기준 이하면 H1을 채택하지 않는다.

### 고정 조건

Si 10×10 nm의 단일 wire, 채널/S·D 도핑 1e16/1e20 cm^-3, 연장 각 20 nm, 300 K, 동일한 S/D 접촉, 하나의 전기적 gate, 둘레 P=0.04 um를 사용한다. 초기 Lg는 40 nm, 기준 SiO2는 1 nm다. gate 누설 모델이 검증되지 않은 동안 총누설·총전력·수명 개선은 평가하지 않는다.

채널 방향 좌표를 u=(z−소스 쪽 채널 경계)/Lg로 정의한다. 채널을 같은 길이의 세 구간으로 나누고 두께 **1−δ, 1, 1+δ nm의 6개 순열**을 모두 비교한다. δ=0.10 nm부터 시작하고 효과 확인 후 0.20 nm로 확장한다.

예를 들어 [0.9, 1.0, 1.1]과 [1.1, 1.0, 0.9] nm는 두께 값과 구간 길이가 같은 거울상 대조다. 얇은 부분의 위치만 바뀌는 효과를 비교할 수 있다.

| 대조군 | 역할 |
| --- | --- |
| 균일 1 nm | 기준 소자 |
| 같은 두께의 6개 순열 | 평균·분산·각 구간 길이를 고정한 배열 비교 |
| 균일 0.9/1.1 nm | 평균 두께 변화와 배열 효과 구분 |
| 균일 1 nm를 3개 region으로만 분할 | 기하 분할·메시 자체의 영향 점검 |
| 각 순열의 거울상과 전기적 S/D 교환 | 물리적 위치 효과와 기하/접촉 코딩 오류 구분 |

같은 평균 두께를 같은 실제 EOT/Cgg라고 부르지 않는다. 순열끼리는 두께 분포가 같아도 3D fringing과 경계 결합은 달라질 수 있다. 균일 1 nm와 비균일 분포는 평균만 같고 ∫1/t에 따른 결합도 다르므로, 균일 기준과의 비교만으로 위치 효과를 분리하지 않는다.

최종 후보에는 1 nm 전이 길이로 단차를 완화한 형상을 별도 대조로 추가한다. 수치 적분으로 평균 두께 보존과 거울 대칭을 확인한다. 단차의 최대 전기장은 메시 특이성에 민감하므로 주결론 지표로 사용하지 않는다. 평활화로 결론이 뒤집히면 이상화된 단차에 의존하는 결과로 보고한다.

## 4. 일함수 보상 프로토콜

고정 일함수와 등누설 결과를 모두 남긴다.

1. 모든 배열을 4.60 eV에서 계산하여 원래의 변화를 확인한다.
2. 각 배열의 균일한 단일 gate work function만 조정해 **Ioff/P=0.04 nA/um**를 맞춘다. 단일 wire 목표는 1.6e-12 A다. 앞으로 적용할 비교 수준이며 새 실측값이 아니다.

초기 탐색 범위는 4.40~4.80 eV다. 이분 탐색은 최대 12회이며 최종 WF 구간 0.1 meV 이하와 Ioff 상대 오차 2% 이하를 동시에 요구한다. 끝점들이 목표를 둘러싸지 못하거나 Ioff가 단조적이지 않으면 무한 확장·자동 외삽을 하지 않고 보류한다. 각 후보의 바이어스/KCL 검사가 통과해야 다음 탐색을 시작한다.

탐색에는 검증된 저비용 1점 취득을 사용할 수 있다. 최종 WF에서는 두 Vds의 전체 왕복 곡선을 새로 계산해 Ioff를 재확인한다. fine에서 WF가 달라져야 하면 fine의 탐색과 성능 곡선을 다시 확인하며 full–fine 보상 WF 차이도 보고한다.

전체 sweep은 기존 Vgs −0.2~0.8 V/0.02 V와 각 51개 목표점을 유지한다. SS 고정 전류창을 덮지 못하면 추출불가로 보고하고 확장 sweep을 별도 등록한다. 창을 임의로 바꾸지 않는다. 작은 SS 차이를 주장할 후보는 0.01 V 간격을 추가 확인한다.

## 5. 측정량과 판정 기준

아래 효과 기준은 새 연구의 설계 선택이다. 기존 공학 목표의 완화나 통계적 p값 기준이 아니다.

| 항목 | 사전 기준 |
| --- | --- |
| 실행과 바이어스 | 코드 0, 정상 ATLAS 종료, 필수 출력; Vds 오차≤1e-6 V; 각 목표점이 정확히 한 번 존재 |
| 원시 데이터 | 적응형 중간점까지 보존하고 native/export·전류 방향·단조성·유한성 검사 |
| KCL | 전 원시점에서≤max(1e-14 A, 최대 단자전류의 0.1%) |
| 기존 공학 목표 | Ion≥100 uA/um, Ioff≤1 nA/um, 비율≥1e6, low Vth 0.1~0.5 V, SS 60~90 mV/dec, DIBL 0~50 mV/V |
| 기존 메시 허용값 | Ion 5%, Ioff 20%, Vth 10 mV, SS 5 mV/dec; 두 Vds와 양방향 모두 적용 |
| 연구용 해상도 | 후보의 full/fine/추가 한 단계 메시와 0.01 V 검사를 이용해 아래 불확실성 u 평가 |
| 등누설 후 Ion 차이 | >max(5%, 3u_Ion), 메시 변경 후 방향 유지 |
| 등누설 후 DIBL 차이 | >max(5 mV/V, 3u_DIBL), 메시 변경 후 방향 유지 |
| 등누설 후 SS 차이 | >max(2 mV/dec, 3u_SS), 고정 창과 표본 간격 검사 통과 |
| 곡선 잔차 | r(Vg)=log10|Id_case|−log10|Id_uniform|. 양쪽 전류가 1e-10~1e-6 A/um인 공통 실제 grid의 RMS/최대값 보고. 최소 6점; floor 의심 시 판정불가 |
| 잔차의 보조 기준 | RMS>max(0.05 decade, 3u_logI). Ioff 또는 Vth 하나만 맞았다는 이유로 곡선 회복을 선언하지 않음 |
| 대칭성 검사 | 균일 소자 및 거울상/S-D 교환의 전류 차이≤max(1e-14 A, 0.5%), Vth 차이≤1 mV |

u는 같은 조건의 최근 두 메시 차이와 표본 간격 검사 차이의 큰 값이다. 서로 다른 두 배열을 비교할 때는 각 배열의 u를 더한 보수적 오차 한계를 사용한다. 3u는 이 한계의 3배이며 통계적 3시그마가 아니다. 우연히 작은 메시 차이에 의존하지 않도록 유망 후보는 추가 한 단계 메시를 필수로 한다.

등누설 조건을 만족하고, Ion/DIBL/SS 중 적어도 하나의 차이가 기준을 넘으며, 반복·대칭성·메시 검사를 통과할 때 H1의 증거로 삼는다. 모델 변경 후 부호나 차이의 존재 여부가 뒤집히면 보편적 보상 한계라고 하지 않고 모델 의존 결과로 분류한다.

장벽 해석을 위해 Vgs=0/0.6 V와 두 Vds에서 채널 중심·계면 인접선의 전위/Ec, 횡단면 전자농도와 전류밀도를 저장한다. 한 중심선의 Ec만으로 전체 3D 전류 경로를 확정하지 않는다.

## 6. 실험 규모와 확대 기준

### B단계: Lg 40 nm의 최소 검증

δ=0.10 nm의 6개 순열과 기준부터 시작한다. 각 조건의 고정 WF와 등누설 WF를 분리한다. 구조 검사→screen→full을 수행하고, 효과가 수치 해상도보다 큰 거울쌍과 기준을 fine/추가 메시로 확인한다. 독립 조건은 다른 작업의 종료를 기다리지 않는다.

현재 BQP의 장시간 수렴 문제를 고려하면 소요시간을 고정해서 약속할 근거가 없다. 처음부터 모든 배열×길이×모델을 fine까지 계산하지 않고 검증 게이트에 따라 확장한다.

### C단계: 보상 한계 지도

B단계에서 차이가 확인되면 Lg 40/30/20 nm, δ=0.10/0.20 nm, 6개 순열을 비교한다. 균일 기준을 길이마다 공유하므로 기하 조건은 **3×(1+2×6)=39개**다. 고정/보상 WF, 메시, 모델, 탐색 시도는 추가 계산이므로 총 39개 덱이라는 뜻은 아니다.

길이 변경은 별도 실험이다. 해당 길이의 기준·메시·모델 적용성 검증을 자식 작업의 선행 조건으로 둔다. 20 nm에서 비국소 수송이나 source–drain 터널링의 영향을 확인하지 못하면 정량적 Ion·극한 스케일링 결론을 보류한다.

B단계에서 차이가 작으면 사전 등록한 δ=0.20 nm의 소규모 반증 검사를 한 번 수행한다. 여전히 기준 이하면 40 nm에서 보상 가능한 범위의 부정 결과를 보존하고 확대를 보류한다. 효과를 만들기 위해 자동으로 20 nm로 줄이지 않는다. 짧은 채널 연구에는 별도의 동기와 모델 근거가 필요하다.

## 7. 실행 패키지와 DAG

| 구성 | 필수 내용 |
| --- | --- |
| metadata.json | 실행 ID, Git HEAD, 덱/모델/구조 해시, 단위, 정규화, 공학 목표·연구 기준 버전 |
| workflow.json | 작업별 선행 조건, 실행 덱, 검증 명령, 최대 병렬 3, 덱/전체 timeout=null |
| tcad/ | 기하·탐색·최종 왕복 덱과 불변 attempt 기록 |
| python/ | 생성기, 구조/단계별 바이어스 검사기, 기존 explicit 검증기, 보상 잔차 추출기 |
| validation/ | 정상 종료·원시 데이터·왕복·메시·등누설·WF 탐색 검사와 미구현 상태의 명시 |
| outputs/ | raw log/str/export, 선택한 attempt와 원시 해시, 실행·목표·물리 보정의 별도 상태 |

검증 명령 계약은 다음과 같이 둔다.

```text
verify_geometry <structure> <spec>
verify_bias_stage <native> <expected_bias>
validate_explicit_bias.py <attempt> --compare <full_attempt> --mode fine
extract_compensation <canonical> <comparison_spec>
```

첫 두 개와 마지막 명령은 **구현 예정 계약**이며 현재 존재하는 CLI가 아니다. 기존 validator는 P=0.04 um·51개 목표점 조건에서 사용한다. 기하나 취득 정의가 달라지면 사양을 먼저 등록한다.

기본 의존관계는 `구조 검사 → screen → full → 해당 조건 fine → 연구 판정`이다. 등누설은 `구조 검사 → WF 후보별 검사 → 최종 full → fine 재탐색/검증 → 판정`이다. 모델 교정은 해당 모델 분기만 막는다.

최대 3개 작업을 원격 독립 세션에서 Python으로 실행한다. 실패한 작업의 자식만 보류하고 각 선행 검증 통과 즉시 후속을 시작한다. 일괄 장벽을 두지 않는다. 모델은 계산을 기다리거나 반복 조회하지 않는다. 계산·통신의 예정 만료 없이 30초 HTTPS/agent 확인, Windows 절전 방지, 10분 회수와 명시적 중지를 유지한다. 입력 장치를 사용하지 않는다.
