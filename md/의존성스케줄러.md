# 순차·병렬 조합을 미리 준비하는 방식

`python/automation/dag_scheduler.py`가 JSON 작업 그래프를 실행한다. 최대3개 동시 실행, 덱당80분 상한, 작업별 폴더/로그, 성공/검증 후 후속 배정, 실패 전파와 전체 세션 만료를 처리한다. 프로세스 종료만으로 성공 처리하지 않고 별도 검증 명령까지 통과해야 한다. 여러 선행 작업을 적으면 모두 통과한 뒤 시작한다. 순환 그래프는 실행 전에 거부한다.

`prepare_workflow.py`를 실행하면 Git 밖 `.local/gaa_workflow_<시각>/`에 다음9개 작업의 입력 덱·설정·검증기·workflow.json·package.zip을 미리 만든다. 이 명령은 원격 작업을 제출하거나 현재 배치를 바꾸지 않는다.

```text
direct_smoke      -> direct_full      -> direct_fine
bicgst_smoke      -> bicgst_full      -> bicgst_fine
equilibrium_smoke -> equilibrium_full -> equilibrium_fine
```

세 가지는 같은 물리 치수/도핑의 수치해법·초기화 비교다. 동일한 산화막 법선 방향 분해능을 유지한 비등방 메시를 쓴다. 한 smoke가 먼저 통과하면 다른 smoke가 진행 중이어도 해당 full을 바로 시작한다. 배치 전체가 끝나기를 기다리지 않는다.

검증기는 ATLAS 정상 종료, 필수 파일, 오류, 실제 바이어스와 export 일치, 유한한 전류, KCL 및 전체 sweep의 단조성을 확인한다. Ion/Ioff·SS·DIBL 등의 목표 충족 여부는 별도로 JSON에 기록한다. 수치 검증 통과만으로 물리 목표/양자 보정/메시 수렴을 통과했다고 선언하지 않는다. fine은 전체 곡선과 지표를 생성하며 coarse와의 메시 수렴 판정은 별도 검토 대상이다.

현재 실행 중인80분 병렬 배치는 이미 전송한 불변 패키지를 그대로 유지한다. 새 스케줄러는 다음 제출부터 적용한다. 근거 없는 동일 덱 재시도는 자동으로 반복하지 않으며, 수정 후보는 새 노드/새 패키지로 사전 정의한다. Python의 대기·실행·검증에는 모델 호출이 없다.
