# GAA 연구 현황 발표 자료 작성 실행 프롬프트

작성일: 2026-11-18 KST

## 요청과 산출물
원격 Linux에 등록된 GAA agent와 파일/상태 API로 접속하여 지금까지의 GAA 연구를 확인한다. 구조 덱과 실제 Silvaco 로그를 근거로 연구 동아리 중간보고용 약 12장 분량의 한국어 마크다운 발표 자료를 작성한다. 그래프·이미지·PPTX는 만들지 않고 모든 수치 비교를 표로 제시한다. 문서는 `md/`, 분석 Python은 `python/`, 검증 기록은 `검증/` 또는 해당 연구의 검증 폴더에 둔다.

## 수행 순서
1. 현재 브랜치·미커밋 변경, AGENTS.md, README, 설계와목표, 최신 인계·원격 자동화 문서를 읽는다. 기존 파일과 계산은 보존한다.
2. runtime 비밀값은 출력하지 않고 기존 control/status 및 agent API를 사용한다. 현재 원격 snapshot을 한 번 수집하고 관측 시각과 회수 시각을 구분한다. 화면 활성화·스크린샷·입력 장치·클립보드는 사용하지 않는다. 접속 불가 시 원인과 마지막 수집 시각을 명시하고 보유 원시 자료로 작업을 계속한다.
3. Python으로 실행 ID별 덱, 상태, 검증 JSON, solver.out, native log, export, 구조 메타데이터를 목록화하고 필요한 자료만 회수한다. 큰 구조 파일은 원격에 보존하고 크기·해시·좌표/영역/전극 등 확인 가능한 정보를 기록한다.
4. 실제 실행 여부·정상 종료·바이어스 범위·KCL·추출 지표·메시 비교·물리 검증·사전 목표 충족을 분리한다. 서로 다른 조건의 수치를 합치지 않으며 A와 A/um를 구분한다. 미완료·실패·추출 불가는 그대로 표시한다. 정적/합성 시험 결과는 소자 성능 근거로 사용하지 않는다.
5. 표지, 연구 목적, 구조와 설계, 물리/수치 조건, 실행 현황, 대표 결과 표, 목표 대비, 메시/BQP 비교, 오류와 한계, 후속 검증, 결론, 근거 목록 순서로 필요한 내용을 구성한다. 필요하면 장 수를 소폭 조정한다. 출처는 저장소 상대 경로와 실행 ID로 연결한다. 외부 문헌의 미확인 수치는 새로 인용하지 않는다.
6. 발표 수치와 출처·단위·행 수를 Python으로 재검사하고 검증 기록을 남긴다. 프롬프트와 최종 발표 자료 경로, 원격 확인 여부 및 핵심 제한을 전달한다. 커밋·push·새 계산 제출·물리 모델 수정은 이 자료 작성 범위에 포함하지 않는다.

## 성공 기준
실제 덱/로그에 추적 가능한 발표용 마크다운과 검증 기록이 존재하고, 그래프가 없으며, 현재 원격 확인 성공 여부와 과학적 검증의 한계가 명확해야 한다. 결과를 보고 기존 연구 목표를 낮추지 않는다.
