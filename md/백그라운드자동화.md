# 다른 PC 작업을 방해하지 않는 실행 방식

2026-11-16 사용자 요청: 이 PC에서 다른 작업을 계속하는 동안 GAA 자동화가 화면·마우스·키보드를 점유하지 않아야 한다.

## 실행 경로

```text
개인 PC: Python controller (UI 입력 없음)
    -> 작업 전용 HTTPS 파일 중계 (token/만료/해시)
    -> Linux agent (로그인된 MobaXterm SSH 세션에서 최초 1회 등록)
    -> 별도 세션의 DeckBuild -run -ascii
    -> DevEdit 3D -> ATLAS -> 원시 로그/구조/수치
    -> 결과 ZIP + 파일별 SHA-256 -> 개인 PC에서 분석
    -> 오류 원인 검토 -> 새 작업 ID/패키지 제출
```

이후 실행·상태 확인·결과 회수·분석에는 컴퓨터 제어 플러그인, 화면 캡처, 키보드/마우스 입력, 창 활성화, 클립보드를 사용하지 않는다. VS Code/Chrome을 앞으로 가져오지 않는다. controller와 터널은 Windows 창 없이 시작한다. agent와 Silvaco는 Linux에서 별도 process session으로 실행한다.

현재 접속 구조는 개인 PC -> Google 원격 데스크톱 -> 학내 Windows -> MobaXterm -> Linux `semicon1`이다. 개인 PC에서 Linux SSH 포트로 직접 연결하는 시험은 timeout이었다. 따라서 기존 로그인된 MobaXterm 안에서 **최초 한 번** agent 등록이 필요하다. 화면을 보았다는 사실만으로 이 등록을 대신했다고 표시하지 않는다. 등록 전에는 로컬 상태를 `WAITING_FOR_AGENT`로 표시하고 실제 시뮬레이션은 `NOT_RUN`이다. 자동화가 아직 없는 원격 실행 권한/전송 경로를 임의로 만들어냈다고 주장하지 않는다.

## 최초 등록과 반복 작업

1. `control.py start`로 새 실행 세션을 만든다. 기존 공식 Cloudflare 바이너리의 고정 해시를 검사하며 새 소프트웨어를 설치하지 않는다. 공개 임시 주소는 특정 작업 파일만 제공하며, 256-bit token과 최대4시간 만료가 적용된다.
2. Git 밖 세션 폴더의 `bootstrap.txt`를 기존 MobaXterm의 Linux shell에서 한 번 실행한다. 이어 token.txt의 이번 작업 토큰을 숨김 입력한다. 암호/PIN/토큰을 채팅이나 Git에 넣지 않는다. controller는 이 과정을 화면 자동화로 대신하지 않는다.
3. `control.py status`에서 실제 `AGENT_READY` 이벤트를 확인한다. 최초 진단 패키지를 먼저 제출한다.
4. 이후 `control.py queue`, `status`, `collect`만 사용한다. 데이터/실행 오류면 새 ID로 수정 패키지를 내며 같은 ID를 중복 실행하지 않는다.
5. `control.py request-stop`는 이번 agent의 자기 작업만 멈춘다. 마지막 결과 업로드와 `AGENT_STOPPED_BY_CONTROL` 확인 후 `close`로 중계만 종료한다. 다른 프로세스/사용자 작업을 종료하지 않는다.

세션이 종료되면 재등록은 필요하다. 오래된 진행 JSON이나 만료된 토큰을 현재 접속 상태로 간주하지 않는다. 활성 상태는 최신 heartbeat·세션 만료·종료 기록을 함께 표시한다. PC가 잠들거나 네트워크가 끊겨도 계속 회수된다고 보장하지 않는다. 물리 모델 수정은 데이터에 맞춰 목표를 바꾸는 작업과 구분한다.

## 현재 상태

웹 화면과 기존 로그인된 shell은 관찰했다. UI 경유 입력은 시험 문자가 전달되지 않았고 `unknown screenshotId screenshot-0`, `user input was detected` 응답이 발생했다. 이 경로는 더 사용하지 않는다. 기존 중계 r01은 agent 등록 없이 종료했다. 새 백그라운드 세션에서는 agent 등록과 진단 자료 회수가 완료됐으며, 실제 실행 상태는 [상태 기록](../연구/01_GAA_IdVg/검증/상태.json)과 [시도 기록](../연구/01_GAA_IdVg/검증/실행시도.md)에서 확인한다.
