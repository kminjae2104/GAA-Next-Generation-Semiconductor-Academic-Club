# 검증 기록

현재 **NOT_VALIDATED**. PASS로 바꿀 때 검사 명령·실제 출력·근거 위치를 함께 기록한다.

| 검사 | 판정 | 근거 파일/명령/한계 |
| --- | --- | --- |
| 폴더·파일 정적 검사 | NOT_VALIDATED | 실제 TCAD 검사와 구별 |
| 실제 Silvaco 정상 종료 / 종료 코드 | NOT_VALIDATED | 미실행 상태 |
| 필수 구조·로그·export | NOT_VALIDATED | 미입력 |
| 네이티브 바이어스 / export 일치 | NOT_VALIDATED | 미입력 |
| 누락·NaN·미수렴 점 | NOT_VALIDATED | 미입력 |
| 단위·정규화·추출 정의 | NOT_VALIDATED | 미입력 |
| KCL | NOT_VALIDATED | 미입력 |
| 메시 수렴 | NOT_VALIDATED | 미입력 |
| 물리 모델·보정·누설 등 검증 범위 | NOT_VALIDATED | 미입력 |
| 사전 목표 충족 | NOT_VALIDATED | 미입력 |

FAIL 또는 NOT_EXTRACTABLE인 결과도 원시 근거와 함께 남긴다. 합성 테스트 통과를 실제 Silvaco 통과로 바꾸지 않는다.
