# 사전계획

계산 전에 작성한다. 결과를 본 뒤 목표를 낮추지 않는다.

| 항목 | 기록 |
| --- | --- |
| 작성자 / 작성일·시간대 | 미입력 |
| 실행 ID / 주제 | 미입력 |
| 목적·가설 | 미입력 |
| 기준 실험 경로·실행 ID·커밋 | 미입력 |
| 변경 변수 / 고정 변수 | 미입력 |
| 구조 치수·재료·도핑·전극 | 미입력 |
| 물리 모델 / 보정 근거 | 미입력 |
| 메시 / 비교할 해상도 | 미입력 |
| 온도 / Vgs·Vds 범위와 간격 | 미입력 |
| 추출 정의 / 단일 A 또는 A/um / 둘레와 정규화 식 | 미입력 |
| 사전 합격 기준 | 미입력 |
| 실패·누락·추출불가 처리 | 미입력 |
| 원본 보관 계획 | 미입력 |
| 선행 조건 / 공유 서버 실행 조율 | 미입력 |
