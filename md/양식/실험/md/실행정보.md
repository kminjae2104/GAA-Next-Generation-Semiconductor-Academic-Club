# 실제 실행 정보

계산 상태: **NOT_RUN**. 아래는 실행한 뒤 실제 근거로 채운다.

| 항목 | 기록 |
| --- | --- |
| 실행자 / 실행 ID | 미입력 |
| 시작·종료 시각과 시간대 | 미입력 |
| Silvaco / DevEdit / ATLAS 버전 | 미입력 |
| 입력 덱·사양 / 입력 SHA-256 | 미입력 |
| 실행 환경(OS 등, 비밀값 제외) | 미입력 |
| 실제 명령 / 작업 디렉터리 | 미입력 |
| 실행 코드 커밋 SHA | 미입력 |
| 종료 코드 / 정상 종료 로그 위치 | 미입력 |
| 라이선스·수렴·경고 메시지 위치 | 미입력 |
| 원시 로그·export·구조 위치 | 미입력 |
| 사전계획에서 달라진 점 | 미입력 |

예약/제출과 정상 종료는 구분한다. 서버 암호·토큰·라이선스 파일을 기록하지 않는다. 계산하지 않았다면 NOT_RUN을 유지한다.
