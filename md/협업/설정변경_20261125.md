이 작업은 실제 Silvaco 계산을 실행하거나 결과 수치를 생성하지 않는다. 기존 원격 계산과 원본을 보존한다. 서명된 주소 문서는 공개되더라도 접속 인증정보가 아니다.

## 통신과 로컬 검증

기존 코드의 private 저장소 전제를 그대로 두면 다음 주소 복구가 실패한다. `allow_public_discovery=true`를 명시적으로 켠 경우에만 공개 접점에 고정 스키마의 서명 문서를 게시하도록 바꿨다. URL·프로토콜·일련번호·서명만 게시하며 접속 토큰과 비밀키는 저장소 밖에 남긴다. 기본 동작은 공개 접점 거부다.

Windows의 해당 중계 controller·자식 프로세스만 교체했다. 같은 runtime·토큰·작업 큐를 보존했고, 원격 agent와 TCAD 계산은 중지하거나 재시작하지 않았다. 15:35 KST 확인에서 인증 HTTPS 200, 비인증 HTTPS 401, 새 주소의 agent heartbeat 수신을 확인했다. [통신 확인 기록](../../검증/협업체계_20261125/transport_migration.json). 이번 전환에서 새 강제 터널 장애 시험·서버 재부팅 시험은 하지 않았다.

기존 자동화 시험 41개와 새 폴더 생성 도구의 보존·경로 시험 4개가 통과했다. 협업 문서 링크와 제출 구조의 정적 검사도 통과했다. 빈 양식과 팀원 입구만 만들었으므로 새 실제 실험은 0개다. 원본 보존과 검증 범위는 [검증 자료](../../검증/협업체계_20261125/README.md)에 기록한다.

코드 소유자 검토 규칙은 `.github/CODEOWNERS`가 main에 게시된 뒤 해당 경로에 적용된다. 이 최초 협업 체계 게시에는 소유자 관리자 예외를 사용한다. 팀원의 제출은 PR과 검토를 기본으로 한다.
