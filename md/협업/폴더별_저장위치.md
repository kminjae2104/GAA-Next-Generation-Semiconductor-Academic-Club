# 자료별 저장 위치

현재 개인 공간은 저장소 최상위 `곽민재/`, `권도현/`, `윤석영/`, `박선우/`, `진/`이다. 아래 예시의 권도현은 본인 이름으로 바꾼다. 모든 명령은 저장소 루트에서 실행한다.

| 만들 자료 | 저장 위치 예시 |
| --- | --- |
| 논문 출처·읽기 기록 | `권도현/문헌/20261125_gate_length.md` |
| 여러 실험에 걸친 계획·연구 노트 | `권도현/md/gate_length_계획.md` |
| 새 TCAD 실행 | `권도현/연구/gate_length/20261125_lg40_r01/` |
| 해당 실행의 사전계획·실행정보·요약 | 위 실행 폴더의 `md/` |
| 해당 실행에 실제 사용한 입력 덱 | 위 실행 폴더의 `tcad/` |
| 해당 실행의 분석 코드 | 위 실행 폴더의 `python/` |
| 해당 실행의 작은 원시 로그·export | 위 실행 폴더의 `검증/raw/` |
| 해당 실행의 검증기록·원본목록 | 위 실행 폴더의 `검증/` |
| 해당 실행의 결과 그림 | 위 실행 폴더의 `그림/` |
| 여러 개인 연구에서 재사용할 도구·그림·검증 | `권도현/python/`, `권도현/그림/`, `권도현/검증/` |

개인 바로 아래의 python/·검증/·그림/과 **각 실행 아래**의 같은 이름 폴더를 구별한다. 특정 실행에 속하는 근거는 실행 ID 폴더에 모아야 조건과 결과를 함께 찾을 수 있다.

## 공통 폴더와 개인 폴더

루트의 `문헌/`, `연구/`, `md/`, `python/`, `검증/`, `그림/`은 기존 공통 자료와 운영 도구다. 개인 공간 아래의 동명 폴더와 구별한다. 새 개인 결과를 루트 공통 연구에 바로 넣지 않는다. 공통 기준 변경이 필요하면 개인 실험의 경로·근거를 연결한 별도 PR로 제안한다.

기존 `연구/01_GAA_IdVg/`와 원격 자동화 경로는 그대로다. 공통 덱을 개인 실행에서 사용할 때는 실행에 사용한 사본과 원본 경로·커밋을 남긴다. 기존 실행 원본을 이동하거나 덮어쓰지 않는다.

## 문헌 검토를 공유하는 순서

1. [문헌 검토 양식](../양식/문헌검토.md)을 `이름/문헌/날짜_주제.md`로 복사한다.
2. 서지정보·원문 위치, 실제 읽은 범위, 소자·모델·조건, 핵심 주장과 근거 위치, 우리 연구와의 차이·미확인 사항을 적는다.
3. 저자의 결과와 본인의 해석을 구분한다. 원문을 읽지 않았다면 초록/검색 요약만 읽었다고 표시한다. 저작권이 있는 논문 전체를 임의로 올리지 않는다.
4. 본인 작업 브랜치에서 해당 문서만 stage·commit·push하고 PR을 만든다. 문헌 검토에 TCAD 실행 결과가 없으면 실행 항목은 N/A로 적는다.

## 이미 예전 구조로 작업 중이라면

과거 `연구/팀원실험/이름/주제/실행ID/`는 현재 `이름/연구/주제/실행ID/`로 바뀌었다. 미커밋 작업은 먼저 보존하고 main을 갱신한다. 예전 브랜치의 새 결과를 옮길 때 목적지에 같은 ID가 있으면 덮어쓰지 말고 비교·조율한다. 아직 공유하지 않은 재실행에는 새 ID를 쓴다. 이동 뒤 문서 링크와 분석 입력 경로를 고치고 정적 검사를 실행한다.

```powershell
py -3.11 python/collaboration/check_workspace.py
```

과거 실행 프롬프트·검증 JSON·일회성 정리 스크립트에 있는 예전 경로는 당시 기록이다. 현재 생성 도구는 `python/collaboration/new_run.py`, 현재 안내는 [시작 안내](README.md)와 이 문서를 따른다. 과거 정리 스크립트를 새 실험 생성용으로 재실행하지 않는다.
