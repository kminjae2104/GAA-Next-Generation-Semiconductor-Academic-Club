# 덱당80분 병렬 실행

사용자의2026-11-16 지시에 따라 최신 게이트 연결 수정판 `tcad/v2_common_gate/`의 smoke/coarse/fine 세 덱을 그대로 사용한다. 구판 중복 덱은 실행하지 않는다. 각 원본 덱 SHA-256을 배치 manifest에 기록하며 수정하지 않는다.

`python/automation/parallel_batch.py`는 세 입력의 해시와 패키지 구성을 검사하고 새6시간 중계 세션 및 병렬 패키지를 준비한다. 최초 Linux agent 등록 후 Python ThreadPoolExecutor가 DeckBuild 프로세스3개를 동시에 시작한다. 각 프로세스 제한은4800초(80분)이며 `cases/<smoke|coarse|fine>/results/`로 출력 경로를 분리한다. 큰 구조 파일은 각 case의 별도 retained_structures에 보존한다. 전송 결과는 배치 results 아래 case별로 회수한다.

실제 서버 시작은 등록/실행 이벤트로 확인해야 한다. 등록 전의 패키지 준비를 실행 완료로 보고하지 않는다. 결과 감시는 백그라운드 Python이 수행하고 모델은 대기하지 않는다. 라이선스 부족으로 동시 체크아웃이 되지 않으면 그 로그를 남기며 성공으로 처리하지 않는다.
