# 실제 로그의 Id–Vg 그래프

각 PNG의 왼쪽은 선형 전류 축, 오른쪽은 로그 전류 축이다. 점은 실제 native log 샘플이며 선은 샘플을 연결한다. 외삽·추가 계산점 생성·누락점 보완은 하지 않았다. 원시 로그는 수정하지 않았다.

| 그래프 | 실제 Vds | 관측 범위와 해석 |
| --- | --- | --- |
| [기준 소자](eq_bicgst_fine_IdVg.png) | 0.6 V | Vgs −0.2~0.8 V, 51점; 목표 바이어스·격자 도달 |
| [BQP fine](bqp_fine_IdVg.png) | 0.6 V | Vgs −0.2~0.58484375 V, 적응형 간격 포함 54점; 미완료 |
| [일함수 4.6 eV fine](wf4p6_fine_IdVg.png) | 0.340703125 V | Vgs −0.2~0.8 V, 적응형 간격 포함 52점; 목표 Vds=0.6 V 미달 |

전류는 단일 wire의 절댓값이다. A/µm로 정규화하려면 A 값을 게이트 둘레 0.04 µm로 나눈다. 조건이 달라 직접 성능 순위를 비교하는 중첩 그래프는 만들지 않았다. 목표 바이어스 도달은 공학 목표·물리 모델 검증 통과를 의미하지 않는다.

재현 코드: `python/presentation/plot_selected_logs.py`. 출처 경로·SHA-256·실제 전압·샘플 수는 [검증기록.json](검증기록.json)에 기록했다. 생성일 2026-11-18. 이 자료는 새 시뮬레이션이 아니라 기존 실제 로그의 시각화다.
